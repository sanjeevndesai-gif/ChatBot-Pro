🟢 WhatsApp

Entry point. Patient or Doctor scans a QR code. WhatsApp Cloud API sends the QR payload as a webhook POST to the Chat Service via the API Gateway.

🔵 Chat Engine Core

ChatEngine — manages per-user sessions in MongoDB.
FlowResolver — loads flow doc from Redis cache, validates input, executes actions, resolves next step.
ValidationEngine — checks input against allowed values with retry limit.

🟠 ActionExecutor

FLOW_REDIRECT — switch to another flow mid-session.
RESOLVE_CHOICE — map user's number (1/2/3) to a list item.
GENERATE_CALENDAR_LINK — build Google Calendar URL.
MONGO_INSERT — save support tickets directly.
API — call auth-service or book_appointment.

🟣 Downstream Services

auth-service — doctor profiles, clinic doctor list, clinics by city.
book_appointment — available slots, create/cancel appointments, patient appointment lookup.

🍃 MongoDB (chatdb)

conversations — active session state.
flows — editable flow definitions (no deploy needed to change steps).
messages — template strings.
support_tickets — raised by SUPPORT_FLOW.

🔴 Redis Cache

Flow documents are cached in Redis via Spring @Cacheable. This prevents repeated MongoDB reads on every message. Cache is invalidated when the service restarts.
